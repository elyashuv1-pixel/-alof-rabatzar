אלוף הוראות הרבצ״ר – חבילת התקנה (PWA)

1. מעלים את כל התיקייה כמו שהיא לאתר עם HTTPS (למשל GitHub Pages, Netlify או Cloudflare Pages, שכולם בחינם).
2. פותחים את הכתובת ב-Chrome באנדרואיד ובוחרים בתפריט "הוספה למסך הבית" או "התקנת אפליקציה".
3. האייקון: icons/icon-192.png ו-icon-512.png (רגילים), ו-maskable-192/512 (לאנדרואיד, עם שוליים בטוחים).

עדכון אייקון בעתיד: מחליפים את הקבצים בתיקייה icons ומעלים את מספר הגרסה (v=3) ב-index.html, ב-manifest.webmanifest וב-sw.js.
אנדרואיד מרענן אייקון של אפליקציה מותקנת רק אחרי שהוא בודק מחדש את ה-manifest, וזה יכול לקחת עד יום. כדי לראות את השינוי מיד, אפשר להסיר את האפליקציה ולהתקין אותה מחדש.
